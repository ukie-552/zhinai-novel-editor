# 📚 织奈编辑器

项目/仓库名称：`zhinai-novel-editor`。

本机运行的 **macOS 原生应用**（纯 SwiftUI + 原生 SQLite，零第三方依赖）。

## 布局（写作优先）

```
┌────┬──────────────┬────────────────┬──────────────────┐
│ 栏 │ 作品导航      │    AI 对话内容    │   正文主编辑区   │
│    │ 章节 / 设定    │   Agent + 技能    │   大纲 + 章节正文  │
│    │ 搜索 / 多会话  │   消息流 + 输入    │   AI 操作 + 自动保存│
└────┴──────────────┴────────────────┴──────────────────┘
多会话是最左侧活动栏中与搜索同级的入口；再次点击当前入口可收起整个导航面板。
```

## 功能

| 功能 | 说明 |
|---|---|
| 🤖 **Agent 设定** | 每个 Agent 可独立配置：头像（emoji）+名称、系统提示词（角色/风格/流程/工具时机/规范）、**自定义模型**、**温度/Top-P/输出上限**（均可跟随全局）、**工具权限开关**、**一个固定 Skill**（每轮注入）、**按需 Skill 索引**（Agent 自行调用）、**知识库挂载**与 **✨ AI 自动生成** |
| 🔧 **梯形工作区工具（Tool Use）** | 递归动态发现：根域 → 子域 → 操作叶子 → 详细 Function Schema。首轮只发送 4 个根域，抵达叶子后按需加载具体工具；可用 LRU 同时保留最多 4 个叶子支持跨域任务。现有 82 个工具覆盖内容、结构、版本、会话、知识与治理域，并继续按 Agent 权限过滤 |
| 📏 **输入/输出大小调节** | 输出上限与输入上下文窗口均支持直接输入任意数值和常用档位；输入预设覆盖至 4M、输出预设覆盖至 256K，上下文指示器显示「注入/上限」与告警 |
| 🗜️ **小说上下文压缩** | 输入达到窗口 80% 时自动启用；保护硬规则、作者意图、当前聚焦、触发设定及最近对话，旧内容按相关性、信息密度和 MMR 风格去重筛选，支持自定义百分比并显示实测节省比例 |
| 🧲 **可拖拽布局** | 导航/正文、正文/AI 助手的分隔线可拖拽；导航、AI 助手及其控制栏可收起 |
| ⬆️ **统一顶部工具栏** | 作品切换/新建、新章节、新对话、AI 操作（续写/润色/检查/大纲）、Agent、设置全部集成到窗口顶部工具栏 |
| 💬 **跨会话 Agent 任务** | 每部作品可开多个独立对话并各自维护历史；Agent 可向其他会话派发后台任务、查询/等待/取消任务。切换书籍或会话不会中止执行，运行状态持久化到 SQLite，异常重启会明确标记为中断而不是伪装完成 |
| 🧵 **每会话资源规划** | 每个后台会话启动时独立获得并持久化核心份额与内存预留；自动估算上下文缓存、梯形工具工作区、工具结果、输出缓冲和基础开销，也可手动指定。调度器累计所有运行会话的预留，资源不足时自动排队，最多同时运行 64 个 |
| 🧮 **上下文预算（防爆）** | 所有注入有硬上限：大纲≤4k字、每章≤6k字、世界书合计≤6k字≤12条、历史≤16条每条≤1.5k字；发送后显示「本次注入 ≈ N tokens · 世界书 N 条 · 前文 N 章 · 历史 N 条」，超 24k 变橙提醒 |
| 🛠 **Markdown Skills** | 技能以本地 `.md` 文件保存，可在应用内新建、编辑、删除；技能库变化会自动反映到下一轮 Agent 技能索引。Agent 可固定使用一个 Skill，或按任务调用 `get_skill` 获取索引中的技能正文 |
| 🗄️ **世界书（Lorebook）** | 参考 SillyTavern：设定条目配触发关键词，对话/写作中出现关键词自动注入；可固定引用 |
| 模型商选择 | 按国产/海外分组，内置 DeepSeek、通义千问、Kimi、GLM、文心、混元、豆包、MiniMax、OpenAI、Claude、Gemini、Mistral、Grok、Groq、Cohere、OpenRouter，以及 Ollama / 自定义接口 |
| 本地数据库 | 原生 SQLite + FTS5 中文全文搜索；独立 `vectors.db` 支持 TXT 分章、向量分块与本地检索 |

## 使用

1. 打开 `build/织奈编辑器.app`（可拖入「应用程序」）
2. ⚙️ 设置 → 选模型商、填 API Key、模型 → 测试连接
3. 对话区只选择稳定的 **Agent**；在 Agent 编辑页可固定一个 Skill，每轮自动生效。技能库会动态生成按需索引，Agent 根据任务自行调用 `get_skill` 获取所需技能正文
4. 侧栏建作品 → 编辑区写大纲 → 设定库建人物/世界观（填触发关键词）
5. 编辑区「AI 操作」直接续写/润色当前章节；右键章节排序；⌘N/⌘⇧N/⌘S/⌘⏎/⌘,

## 数据

`~/Library/Application Support/ZhinaiNovelEditor/`（`novels.db` + `config.json` + `agents.json`，全部本机）。首次启动会自动迁移旧版数据。

## 构建与自检

```bash
./macos/build_app.sh        # 需要 Xcode 命令行工具
# 无头全链路自检（19 项）：
swiftc -O -swift-version 5 -target x86_64-apple-macosx13.0 \
  macos/Models.swift macos/DB.swift macos/LLM.swift macos/Skills.swift macos/SelfTest.swift \
  -o /tmp/selftest -lsqlite3 && node tools/mock_llm.js & \
  AINOVEL_DATA_DIR=/tmp/t AINOVEL_TEST_BASEURL=http://127.0.0.1:19001/v1 /tmp/selftest
```

## 后续
